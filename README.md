# CUYOCO Collaboration

Open questions, small demonstrations and checklists from CUYOCO, published for critique and reuse.

| Pilot | Question | Contents |
|---|---|---|
| 01 | Under which conditions may AI agents permanently change an organisation's knowledge? | `pilot-01/demo` (synthetic, Python), `pilot-01/checklist` (German), discussion |

Each pilot links to a plain-language article on https://cuyoco.com. The examples use **synthetic data only**.

## Taking part

- Ideas, critique, experience: **Discussions** (one thread per pilot question).
- A defect in an example: **Issues**, with steps to reproduce.
- Code changes: pull requests are welcome for the published examples; see `CONTRIBUTING.md`.

We review contributions weekly and record what we adopted, tested, rejected or deliberately left open. A popular
request is not automatically a priority: we weigh technical and practical value separately.
